# 🎬 Moview

A dynamic movie discovery app built with vanilla JavaScript and the TMDB API. Browse popular movies on load, search by title, and see color-coded ratings at a glance.

🔗 **[Live Demo](https://hasankoparan.github.io/Moview)**

-----

## ✨ Features

- 🎥 Browse popular movies on page load
- 🔍 Live search by movie title
- ⭐ Color-coded rating indicators:
  - 🟢 Green — 8.0 and above
  - 🟠 Orange — 5.0 to 7.9
  - 🔴 Red — below 5.0
- 🖼️ Movie poster cards with title, rating and overview
- 📱 Fully responsive layout
- ⚡ Real-time data from TMDB API

## 🛠️ Built With

- **HTML5** — Semantic structure
- **CSS3** — Card layout and responsive design
- **JavaScript (ES6+)** — Fetch API, async/await, DOM manipulation
- **[TMDB API](https://www.themoviedb.org/)** — Real-time movie data

-----

## 🧠 JavaScript Concepts Used

- `fetch()` with `async/await`
- Dynamic DOM creation and rendering
- Live search filtering
- Conditional color coding based on rating value
- Template literals for card HTML
- API key authentication via query params

-----

## 📁 Project Structure

```
Moview/
├── index.html      # Main page structure
├── style.css       # Card styles and responsive layout
└── apps.js         # TMDB API fetching and DOM logic
```

## 🚀 Getting Started

```bash
git clone https://github.com/HasanKoparan/Moview.git
```

Then open `index.html` in your browser — or use Live Server in VS Code.

> ⚠️ Requires a free TMDB API key. Get yours at [themoviedb.org](https://www.themoviedb.org/)
